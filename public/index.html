GraphQL vs REST vs gRPC

Same book catalog, three API styles. Click each button to see how the request and response differ — REST uses fixed URLs, GraphQL lets you pick fields, and gRPC uses a binary protobuf contract.

REST

HTTP + JSON

Endpoint: GET /api/books/2

Fixed response shape — always returns all book + author fields.

GET /api/books/2

GraphQL

HTTP + JSON

Endpoint: POST /graphql

Client selects only title and author.name.

{ book(id: "2") { title author { name } } }

gRPC

HTTP/2 + Protobuf

RPC: BookService.GetBook

Strongly typed contract in book.proto. Binary on the wire.

rpc GetBook(GetBookRequest) // id: "2"
